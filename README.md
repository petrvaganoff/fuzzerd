# Fuzzerd

> This project is currently under development.

## Introduction

Fuzzerd is a utility for managing and monitoring fuzzing campaign pipelines, orchestrating vulnerability discovery tools for large open-source projects.

## How to build?

```bash
git clone --recurse-submodules https://github.com/petrvaganoff/fuzzerd.git

cmake -B build
cmake --build build

sudo build/fuzzerd
```
